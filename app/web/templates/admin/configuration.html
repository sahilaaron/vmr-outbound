Deployment settings

environment only — read-only here, by design

These are deployment or security boundaries, not product operation. Several are enforced by validation that runs once before the service starts serving, so a switch that could change them at runtime would walk straight past the check that exists to refuse exactly that state. Secrets — database URLs, OAuth client secrets, provider API keys, encryption and session keys — are never shown here at all, only whether they are configured.
