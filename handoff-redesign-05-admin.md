## What changed

**Admin (`/app/admin`, administrators only, same shell)** — six sections with one nav (`_admin_nav.html`):
1. **Home / Health** — queue depth, stale leases, execution mode, "needs an administrator" items, Campaign outcomes with failed-job counts, release id (from `AdminWorkbenchReader.overview()`).
2. **Capabilities** — the Agent controls (`/app/admin/agents`, moved in slice 1), now titled Capabilities.
3. **Providers & Spend** — links out to the existing `/admin/providers` (spend surface unchanged, `PROVIDER_SPEND_SURFACE`).
4. **Users & Access** — `/app/admin/users`.
5. **Data tools** — Imports, captures waiting on a company, identity conflicts (`/review`), verification console, suppression list, Company Intelligence backfill, local tools when local.
6. **Diagnostics** — per-Campaign diagnostics (where people stopped and why) plus links into the Workbench's failures / stages / system.

**Legacy customer twins retired** — `app/web/routes.py` −1,266 lines: the old Contacts (list, add-to-campaign, detail, labels/notes, generate-candidates, per-contact verify), Companies, Campaigns (list/create/detail/settings/offerings), Knowledge Base (all sections + generate) pages and the later-phase "isn't available yet" stubs are removed with their templates (kb_*.html, contacts/contact_detail, companies/company_detail, campaigns/campaign_detail, unavailable, _email_intel). The URLs **308-redirect** into the product: `/contacts[/{id}]` → `/app/people[/{id}]`, `/companies[/{id}]` → `/app/companies[/{id}]`, `/campaigns[/…]` → `/app/campaigns[/…]`, `/knowledge-base[/{section}]` → `/app/library[/…]`. Links generated by services (`captures/intake.contact_url`, `crm/records.detail_url`) point at `/app/people/{id}`. The legacy shell's rail links back into the product; the admin Workbench's KB link is now Library. Person/Company pages' admin button is **Diagnostics** → `/admin/contacts/{id}` / `/admin/companies/{id}`.

**Policy** — `_ADMIN_ONLY_UNSAFE_PATTERNS` drops the `/contacts/{id}/verify` and `/knowledge-base/*` entries (routes gone). Nothing became more permissive: `PROVIDER_SPEND_SURFACE` 9 → 7 because two spend routes ceased to exist.

## Retired on purpose (deferred backlog, not lost data)
- `POST /knowledge-base/generate` (Claude-CLI knowledge-base generation) — candidate for an Admin data tool later.
- Per-contact `POST /contacts/{id}/verify` and `generate-candidates` — the verification console (`/verification`, admin verbs) remains.
- Contact labels/notes editing on the legacy detail page — not on the person page yet.
